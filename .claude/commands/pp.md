Push current code to GitHub.

Steps:
1. Run `git status` to see what has changed
2. Run `git diff --stat` to summarise changes
3. Stage all changes: `git add .`
4. Write a concise commit message based on what changed (imperative tense, no fluff)
5. Commit with that message (include Co-Authored-By trailer)
6. Push to origin main: `git push`
7. Confirm push succeeded and show the commit hash
